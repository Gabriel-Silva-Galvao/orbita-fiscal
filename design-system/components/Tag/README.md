Quatro rótulos pequenos: selo, aba, rótulo a definir e sobretítulo.

- Selo (`COMPLETO`): fundo `brand`, texto `on-brand`, `label`. Um por tela.
- Aba: pílula com borda `line-strong`; a selecionada usa fundo `ink` e texto `bg`.
- Rótulo “a confirmar” ou “a definir”: contorno tracejado `brand`, `radius-sm`, nunca quebra de linha. Marca o que ainda não é promessa.
- Sobretítulo (`PLUGIN PARA CLAUDE`): `label` em `brand`, só no hero, onde informa algo que o título não diz. Não repita sobretítulo acima dos títulos de seção: o título carrega a hierarquia sozinho.
- Quem consome fornece o texto; cuide para o rótulo ficar dentro do mesmo elemento do texto que ele qualifica.
